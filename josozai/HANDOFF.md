## 3. 残作業：Vercelでの公開

**ユーザーがブラウザで操作する必要がある。** 理由は第5章を参照。

Vercel の New Project から：

1. `quietbranch-lab/reg-watch` を **Import**
   （一覧に無ければ「Adjust GitHub App Permissions」でアクセス許可）
2. Configure Project で以下を設定
   - Framework Preset: **Other**
   - **Root Directory: `josozai`** ← ここだけ必須。Editボタンから選択
   - Build and Output Settings: **触らない**（空のまま）
   - Project Name: 任意
3. **Deploy**

`https://＜プロジェクト名＞.vercel.app` が発行される。

Root Directory の指定が唯一の必須作業。ビルド不要の静的サイトなので他は既定でよい。

## 4. 掲載データと、その確定根拠

数値は**推測で書かない**方針。すべてメーカー公式または商品パッケージ表記で裏付け済み。

| 商品 | 種別 | 内容量 | 効き目 | 持続期間 | 散布面積 | 参考価格 |
|---|---|---|---|---|---|---|
| サンフーロン | 液 | 500mL | ★4 | 予防効果なし | 約250〜1,000㎡ | 925円 |
| ラウンドアップ マックスロード | 液 | 1L | ★5 | 予防効果なし | 約500〜2,000㎡ | 3,391円 |
| クサノンGT粒剤 | 粒 | 800g | ★5 | 最長 約1年 | 約27〜160㎡ | 1,536円 |
| ネコソギトップF粒剤 | 粒 | 800g | ★5 | 約5〜9か月 | 約20〜160㎡ | 1,482円 |
| ネコソギブロックV粒剤 | 粒 | 600g | ★4 | 約4〜6か月 | 約15〜120㎡ | 1,414円 |

根拠の補足：

- **液剤2点の散布面積**は希釈倍率から算出。サンフーロン500mLは25倍希釈で250㎡・
  100倍希釈で1,000㎡。ラウンドアップ1Lはその倍。
- **クサノンGT** の散布面積は、ユーザー提供のパッケージ画像の
  「160㎡〜27㎡（約48〜8坪）」表記で確定。Web検索では確認できなかった数値。
- **ネコソギ2点**はレインボー薬品の公式製品情報およびパッケージ表記で一致確認済み。
- **効き目の★** は5製品内での相対的な目安。公式指標ではなく、その旨を注記に明示。
- **価格**は2026年9月時点のユーザー提供値。注記に「変動する」旨を明示。

### Amazonリンクの方針

商品ページを確実に特定できたものだけ直リンク、それ以外は検索リンク。

- ラウンドアップのみ直リンク（`https://www.amazon.co.jp/dp/B001GHEY9Y`）
- 残り4点は `https://www.amazon.co.jp/s?k=商品名` 形式の検索リンク

**ASINを推測で書かないこと。** この環境からはAmazonに到達できず検証不能なため、
確証のないASINを直リンクにすると誤った商品ページへ誘導する恐れがある。

## 5. 環境の制約（重要）

このリモート実行環境は、**GitHubとパッケージレジストリ以外への外部アクセスが
ネットワークポリシーで遮断**されている（CONNECTに対し403）。

到達できないことを実測で確認済みの例：

- `m.media-amazon.com`、`www.amazon.co.jp`
- `www.rainbow-f.co.jp`、`www.kincho-engei.co.jp`、`www.nissan-chem.co.jp`
- `vercel.com`、`api.vercel.com`
- その他一般サイト全般

この結果、以下ができない：

- **商品画像をWebからダウンロードすること** → ユーザーに添付してもらう必要がある
- **Vercel CLIでのデプロイ** → 認証の問題ではなく、通信自体が通らない
- **公開後のURLを開いての表示確認** → ユーザーにスマホで確認してもらう
- **WebFetchによるページ取得** → 同様に遮断される

使えるのは **WebSearch のみ**（検索結果の要約テキストは取得できる）。

### 画像に関する厳守事項

**取得できない商品画像を、架空のパッケージや自作イラストで代用してはならない。**
取得できない場合は作業を止め、どの画像が取得できなかったかを報告すること。

現在の5点はユーザーがスマホから添付したJPEGを、Chromium + Playwright の
canvas経由で長辺600pxのWebPに変換したもの（EXIF等のメタデータは除去済み）。
同じ手順は前セッションで実績あり。変換ツール（cwebp / ImageMagick / PIL）は
この環境に入っていないため、Chromiumを使う必要がある。

## 6. 変更するときの注意

- **画像の差し替え**：同じファイル名で `josozai/assets/` に上書きすればHTMLの変更は不要。
  拡張子を変える場合は `index.html` の `<img src="assets/...">` も合わせて修正する。
- **このリポジトリの本来の用途は別物**（官庁の新着情報を集める `reg-watch`）。
  毎朝BotがGitHub Actionsで `main` に自動コミットするため、その度にVercelが
  再デプロイされるが、静的サイトなので比較ページの内容は変わらない。
  `josozai/` 以外のファイルには触らないこと。
- **作業ブランチ**：`claude/herbicide-comparison-page-9l3ix4`。
  既に `main` にマージ済み（`4104c45`）。Vercelは `main` を見るため、
  以降の修正も `main` に反映される必要がある。
