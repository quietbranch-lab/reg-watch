# 商品画像の置き場所

`index.html` は、このフォルダ内の画像を相対パスで参照しています。
以下の5ファイルを置くと、各商品カードに画像が表示されます。

| ファイル名 | 商品 |
|---|---|
| `sunfulon.webp` | サンフーロン 500mL |
| `roundup.webp` | ラウンドアップ マックスロード 1L |
| `kusanon.webp` | クサノンGT粒剤 800g |
| `nekosogi-top.webp` | ネコソギトップF粒剤 800g |
| `nekosogi-block.webp` | ネコソギブロックV粒剤 600g |

- `.webp` 以外（`.jpg` / `.png`）を使う場合は、`index.html` の
  `<img src="assets/...">` の拡張子も合わせて変更してください。
- 画像が無い間は、カードに「商品画像 未取得」のグレー枠が表示されます。
- 推奨: 縦長（およそ 3:4）、幅 400〜800px 程度。

## 現状

このセッションのネットワークは GitHub とパッケージレジストリ以外への
外部アクセスが遮断されているため、5商品すべての実物商品画像を取得できませんでした。
架空のパッケージ画像で代用することは行っていません。
